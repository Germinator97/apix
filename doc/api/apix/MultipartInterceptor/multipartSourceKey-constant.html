multipartSourceKey constant

String const multipartSourceKey

Key under which the caller's original data map rides on the request, so a replayed attempt can be given a body of its own.

A FormData is single-use — dio finalizes it into a stream — and two things in apix replay a request without the caller asking: AuthInterceptor after a token refresh, and RetryInterceptor on a retryable status. Both re-enter the chain with the same RequestOptions, so without this the second attempt carried a body that had already been consumed.
